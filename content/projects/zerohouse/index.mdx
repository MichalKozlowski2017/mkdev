Commercial website for **ZeroHouse** — a brand of energy-independent homes with
developer inventory and individual build offers.

## Highlights

- Content and property listings managed in **Sanity**, rendered with **Next.js**.
- Sections for technology, developer offer, individual offer, and contact.
- Rich media presentation of house models and available units (status, size, price).

## Note

Source code is treated as a client project (no public repo link here). The live site
is at [zerohouse.pl](https://www.zerohouse.pl/).
